Bold Penguin E2E Framework

Execution, test-data, locator, reporting, and troubleshooting guide.

1. What this framework does

The framework reads Nationwide URLs from a CSV file and validates Bold Penguin CTAs in desktop Chrome and mobile Chromium. Playwright automatically captures a trace, screenshot, and video when a test fails.

DesktopDesktop Chrome viewport and user agent.
MobileiPhone 12 emulation using Chromium.
Test dataOne Playwright test is created for each CSV URL.
ReportsHTML report plus failure artifacts.

2. First-time setup

cd C:\NW_Testing\bold-penguin-button-validator
npm install
npx playwright install chromium

Run these commands from the project folder. Use Node.js 18 or newer.

3. CSV test data

The default file is url.csv. It must contain a header named URL, url, or Url.

URL
https://www.example.com/page-one
https://www.example.com/page-two

The parser is maintained in utils/test-data.js. Empty rows are ignored.

Use another CSV

$env:BP_URL_FILE = '.\data\smoke.csv'
npm run test:e2e
Remove-Item Env:BP_URL_FILE

5. Reports and traces

HTML report

npx playwright show-report .\reports\playwright-report

Find a failure trace

Get-ChildItem .\test-results -Recurse -Filter trace.zip

Copy the resulting path, then open it:

npx playwright show-trace .\test-results\<test-folder>\trace.zip

Do not guess the test folder name. Playwright shortens names, so always find the actual trace.zip first.

FolderContents
reports/playwright-reportInteractive HTML report.
test-resultsTrace, screenshot, video, and test attachments for failures.

6. Locators and framework structure

URLs belong in url.csv. Page-specific selectors belong in the Page Object Model, not in the CSV.

PathResponsibility
pages/BoldPenguinPage.jsPage actions and CTA locators.
tests/bold-penguin.spec.jsTest creation, execution, and assertions.
utils/test-data.jsCSV loading and URL validation.
playwright.config.jsProjects, timeouts, traces, screenshots, videos, and reporters.
run-desktop-and-mobile.jsDesktop/mobile command wrapper.

Current CTA discovery includes links, buttons, role buttons, router links, and elements with URL attributes. If a site changes its markup, update the page object or validation selector logic rather than changing url.csv.

7. Test hooks

Hooks are automatic setup and cleanup steps in the Playwright test lifecycle. The current test file uses two hooks:

HookWhen it runsCurrent purpose
test.beforeEachBefore every URL testSets action timeout to 15 seconds and navigation timeout to 30 seconds.
test.afterEachAfter every URL testLogs failed test names and the Playwright artifact directory.
 
test.beforeEach(async ({ context }) => {
  context.setDefaultTimeout(15000);
  context.setDefaultNavigationTimeout(30000);
});

test.afterEach(async ({}, testInfo) => {
  if (testInfo.status !== testInfo.expectedStatus) {
    console.error(`Test failed: ${testInfo.title}`);
  }
});

Do not manually close the Playwright context. Playwright creates an isolated context for each test and closes it automatically afterward.

8. Troubleshooting

“CSV not found”

Run from the project directory or provide an absolute/relative file through BP_URL_FILE.

“No URLs found”

Check that the CSV has a header row and that every URL is in the URL column.

Trace file does not exist

First run Get-ChildItem .\test-results -Recurse -Filter trace.zip. A trace is created only for a failed test because the configuration uses retain-on-failure.

Navigation returns to the wrong URL

Open the trace and inspect the clicked CTA, redirects, popup pages, and final URL. A redirect to a Bold Penguin endpoint may indicate an application navigation issue rather than a Playwright setup issue.

Browser executable is missing

npx playwright install chromium

9. Useful cleanup

Remove-Item .\test-results -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\reports\playwright-report -Recurse -Force -ErrorAction SilentlyContinue

Only remove generated folders such as test-results and reports/playwright-report. Keep url.csv, the page object, tests, configuration, and utility files.
